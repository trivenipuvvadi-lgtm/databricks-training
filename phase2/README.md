
# Phase 2 – SQL to PySpark

## Overview

This phase focuses on converting SQL queries into equivalent PySpark DataFrame operations using **Databricks Community Edition**.

The project uses customer and sales datasets to perform aggregations, joins, filtering, and business analysis using PySpark DataFrames.

---

## Platform

- Databricks Community Edition

---

## Datasets

- Customers Dataset
- Sales Dataset

---

## Project Workflow

### Step 1 – Create Spark Session
- Initialize SparkSession.

### Step 2 – Load Data
- Read Customers CSV.
- Read Sales CSV.
- Display datasets.
- Print schemas.

### Step 3 – Data Cleaning
- Remove records with missing customer IDs.
- Prepare clean datasets for analysis.

---

## Exercises

### Exercise 1 – Total Order Amount for Each Customer
- Calculate the total spending of each customer.

### Exercise 2 – Top 3 Customers by Total Spend
- Identify the top three customers based on total spending.

### Exercise 3 – Customers With No Orders
- Find customers who have not placed any orders using Left Anti Join.

### Exercise 4 – City-wise Total Revenue
- Calculate total revenue generated by each city.

### Exercise 5 – Average Order Amount per Customer
- Calculate the average order value for each customer.

### Exercise 6 – Customers With More Than One Order
- Count customer orders and identify repeat customers.

### Exercise 7 – Customer Spending Report
- Sort customers based on total spending.
