
# Phase 4 – PySpark Mini Project

## Overview

This mini project demonstrates an end-to-end ETL (Extract, Transform, Load) pipeline using **PySpark** in **Databricks Community Edition**.

The project reads customer and sales datasets, performs data cleaning and validation, applies DataFrame transformations, generates business insights, and exports the final reporting table.

---

## Platform

- Databricks Community Edition

---

## Datasets

The project uses two datasets:

- Customers Dataset
- Sales Dataset

---

## Project Workflow

### Step 1 – Create Spark Session
- Initialize the SparkSession.
- Configure the PySpark application.

### Step 2 – Load Data
- Read the Customers dataset.
- Read the Sales dataset.
- Display sample records.
- Verify the schema.

### Step 3 – Data Cleaning
- Remove records with NULL customer IDs.
- Remove duplicate records.
- Filter invalid sales records.
- Convert the sale date to Date format.

### Step 4 – Data Integration
- Join the Customers and Sales DataFrames using an Inner Join.

---

## Business Tasks

### Task 1 – Daily Sales Report
- Calculate total sales for each day.

### Task 2 – City-wise Revenue
- Calculate the total revenue generated by each city.

### Task 3 – Top 5 Customers
- Identify the top five customers based on total spending.

### Task 4 – Repeat Customers
- Find customers who placed more than one order.

### Task 5 – Customer Segmentation
Classify customers into spending categories:

- Gold
- Silver
- Bronze

### Task 6 – Final Reporting Table

Generate a report containing:

- Customer Name
- City
- Total Spend
- Order Count
- Customer Segment

### Task 7 – Export Report

- Save the final report as a CSV file using overwrite mode.
