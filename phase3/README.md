# Phase 3 – ETL Pipeline

## Overview

This phase focuses on building an ETL (Extract, Transform, Load) pipeline using **PySpark** in **Databricks Community Edition**.

The project processes customer and sales datasets by performing data cleaning, validation, transformations, and report generation.

---

## Platform

- Databricks Community Edition

---

## Datasets

- Customers Dataset
- Sales Dataset

---

## ETL Workflow

### Step 1 – Read Data
- Load customer and sales datasets.

### Step 2 – Data Cleaning
- Remove NULL values.
- Filter invalid records.
- Validate datasets.

### Step 3 – Business Analysis

#### Task 1 – Daily Sales Report
- Calculate total sales for each day.

#### Task 2 – City-wise Revenue
- Calculate revenue generated by each city.

#### Task 3 – Repeat Customers
- Identify customers with more than two orders.

#### Task 4 – Highest Spending Customer
- Find the highest spending customer in each city.

#### Task 5 – Final Reporting Table
Generate a report containing:

- Customer ID
- Customer Name
- City
- Total Spend
- Order Count
