# PySpark Assignment

## Assignment Overview

This repository contains the solutions to a PySpark assignment completed using Databricks. The assignment is designed to build practical knowledge of PySpark DataFrame operations, transformations, and built-in functions.

The assignment uses manually created DataFrames instead of external datasets and covers various PySpark concepts through different sections.

---

## Platform

- Databricks Community Edition
---

## DataFrames Used

The assignment uses the following DataFrames:

- Employee DataFrame
- Department DataFrame
- Manager DataFrame
- New Employee DataFrame
